# 🌍 Booki - Agence de voyage

Projet d'intégration web : création de la page d'accueil d'une agence de voyage nommée **Booki**, dans le cadre de ma formation **Développeur Web** chez OpenClassrooms.

🌐 **Voir le site en ligne** : [https://M-bu-y.github.io/Booki/](https://M-bu-y.github.io/Booki/)  
*(À activer via GitHub Pages après la mise en ligne)*

---

## 📌 Contexte du projet

L'objectif est d'intégrer la maquette **Booki** en HTML et CSS, en respectant les contraintes suivantes :

- **Intégration fidèle** à la maquette Figma (version desktop, tablette et mobile).
- **Responsive design** : adaptation aux écrans desktop, tablette et mobile.
- **Code propre et sémantique** : utilisation des balises HTML5 et du CSS3 moderne.
- **Accessibilité** : balises `alt`, titres hiérarchiques, etc.

## 🛠️ Technologies utilisées

![HTML5](https://img.shields.io/badge/-HTML5-E34F26?logo=html5&logoColor=white&style=flat)
![CSS3](https://img.shields.io/badge/-CSS3-1572B6?logo=css3&logoColor=white&style=flat)

- **Structure** : HTML5 sémantique (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **Style** : CSS3 personnalisé (Flexbox, Grid, animations légères, Media Queries).
- **Méthodologie** : BEM (Block Element Modifier) pour nommer les classes CSS.
